# AI Clinic Assistant — RAG & Hugging Face Model Evaluation Platform

> **Academic Value-Added Course Project**  
> A complete, professional, full-featured web application for evaluating and head-to-head comparing Hugging Face Language Models on a controlled Retrieval-Augmented Generation (RAG) pipeline using synthetic clinic knowledge base and a standardized 20-question benchmark suite.

---

## 📌 Project Overview & Objective

The primary objective of this project is to conduct a **fair, controlled, and empirical evaluation** of open-source Large Language Models (LLMs) available on Hugging Face when deployed as RAG clinic assistants.

To guarantee a fair comparison:
1. Both models evaluate against the **SAME 25 synthetic clinic knowledge base entries** (`clinic_faq.json`).
2. Both models process the **SAME 20 benchmark test questions** (`test_questions.json`).
3. Both models receive the **SAME top-1 retrieved context** and similarity scores generated by a real vector space semantic search engine.

## 📊 The Four Required Evaluation Metrics

The system continuously evaluates and displays four core metrics across Model A and Model B:

| Metric | Calculation Formula | Target | Description |
| :--- | :--- | :---: | :--- |
| **1. Retrieval Accuracy** | `(Correct Retrievals / Total Questions) × 100` | High | Percentage of benchmark questions where `Retrieved FAQ ID == Expected FAQ ID`. |
| **2. Answer Correctness** | `(Correct Answers / Total Questions) × 100` | High | Factual agreement between the model's generated answer and the ground truth. |
| **3. Answer Relevance** | `(Relevant Answers / Total Questions) × 100` | High | Measures whether the answer directly addresses the intent of the user query. |
| **4. Hallucination Rate** | `(Hallucinated Answers / Total Questions) × 100` | **Low** | Detects ungrounded or fabricated claims outside the retrieved context (**lower is better!**). |

## 🎛️ Dynamic Hugging Face Model Selection

The application provides a dedicated **Model Configuration** interface allowing users to dynamically switch models evaluated in the RAG pipeline.

### Supported Models:
- **Preset Models**:
  - `mistralai/Mistral-7B-Instruct-v0.2`
  - `meta-llama/Llama-3.2-3B-Instruct`
  - `Qwen/Qwen2.5-7B-Instruct`
  - `google/gemma-2-9b-it`
  - `HuggingFaceH4/zephyr-7b-beta`
- **Custom Model ID**: Accepts any custom Hugging Face model identifier (e.g. `organization/model-name`).
- **Swap Models**: Quickly swap Model A and Model B positions.
- **Dynamic Updates**: Model titles and metrics update dynamically across all dashboard screens, tables, and CSV exports.

## 🔑 Environment Configuration & Security

The application uses Hugging Face Inference API keys securely:

1. Copy `.env.example` to `.env.local`:
   ```bash
   cp .env.example .env.local
   ```
2. Add your Hugging Face API Token:
   ```env
   HUGGINGFACE_API_KEY=hf_your_actual_token_here
   ```
3. `.env.local` is listed in `.gitignore` to prevent committing secrets.
4. **Fallback Benchmark Engine**: If an API key is missing or HF endpoints time out, the system automatically uses the academic evaluation engine to guarantee continuous demonstration.

## 🚀 Installation & Local Execution

1. Clone or open the repository directory:
   ```bash
   cd AI-Clinic-Assistant-Evaluation
   ```
2. Install dependencies (optional for local dev server):
   ```bash
   npm install
   ```
3. Start the application:
   ```bash
   npm start
   ```
4. Open your browser at `http://localhost:3000` or double-click `index.html`.

## 🧪 Viva Presentation & Demonstration Guide

During academic evaluation or viva presentation:

1. **Dashboard Overview**: Present the 4 KPI cards and the **Grouped Bar Chart** comparing Model A vs Model B.
2. **Model Configuration**: Demonstrate dynamic model selection, custom model ID entry, and swapping.
3. **Live Run Evaluation**: Click **Run Full Evaluation** to show real-time question-by-question progress (`7 / 20`) and live status updates.
4. **Question Detail Drawer**: Click any row in the results table to reveal the detailed drawer showing user question, ground truth, retrieved context, similarity score, and model outputs.

6. **CSV Export**: Click **Export CSV Report** to download the complete raw dataset for your academic project report.
